# Переработка виджета системного монитора — дизайн

- **Дата:** 2026-10-02
- **Статус:** утверждён
- **Затрагивает:** `main.py`, `metrics.py`, `overlay.py`, `run_widget.py`, `Monitor.spec`, `README.md`, `AGENTS.md`, `.gitignore`

## Цель

Виджет выглядит устаревшим и ненадёжным одновременно. Переработка решает обе половины: единый
визуальный язык вместо разнородной палитры и разобранная архитектура вместо `QLabel` с
HTML-строкой, который сам себе верстает вид.

Главный критерий успеха: панель, нарисованная по этому документу, выглядит на 100 % и 150 % DPI
одинаково, а её лог не растёт отн��сительно скорости работы.

## Что именно не так сейчас

Дизайн:

- Палитра `#33ff99` / `#FF00FF` / `#82aaff` / `#FF8C00` — четыре несвязанных неоновых цвета без
  общей логики. Цвет не несёт смысла: зелёный CPU и оранжевый RAM означают одно и то же.
- `WIDGET_ALPHA_PERCENT = 0` — на старте фон полностью прозрачен, текст висит над рабочим столом
  без контейнера. Читается как недоделанная заглушка.
- Весь текст — `Consolas 12pt Bold`. Различия между подписью и значением только через `<b>`,
  колонки не выровнены, числа прыгают по ширине при изменении разрядности.
- Нет истории: цифры меняются, но не видно направления.
- Режим «случайный цвет» по правому клику — главный источник ощущения дешёвой поделки.
- Выход по средней кнопке мыши невозможно обнаружить; трей-иконки нет.

Техника:

- Четыре вызова `pynvml.nvmlInit()` на одну выборку (по одному в `gpu_utilization`,
  `gpu_vram_used_gb`, `gpu_vram_total_gb`, `gpu_temp`). На машине без NVIDIA это восемь
  исключений каждые две секунды.
- `gpu_utilization() -> str` — строковая типизация; вызывающая сторона компенсирует через
  `float(m.gpu_utilization())`.
- `gpu_temp()` возвращает `0.0` при недоступности, WMI-фолбэк нагрузки синтезирует
  `ratio * 30`. Обе величины — выдумка, а не измерение.
- `psutil.cpu_percent(interval=0.1)` блокирует UI-поток на 100 мс каждые две секунды.
- Ручной детект двойного клика из счётчика и двух `QTimer` вместо `mouseDoubleClickEvent`;
  `_double_click_timer` создаётся заново на каждый клик — утечка Qt-объектов. История из 13
  коммитов показывает, во что это вылилось.
- Два источника правды для прозрачности: `_bg_alpha_percent` и свойство `bg_alpha`; часть путей
  обходит сеттер и пишет напрямую.
- `run_widget.py` импортирует несуществующий пакет `widget.main` и создаёт второй
  `QApplication`. Файл нерабочий.
- `Monitor.spec` объявляет `overlay.py` и `metrics.py` как `datas`, а не как модули.
  Дополнительно `*.spec` в `.gitignore`, поэтому спека сборки не версионируется вовсе — сборка
  невоспроизводима.
- `README.md` и `AGENTS.md` описывают `metrics_history.log`, который никто не пишет.
- `logger.debug` на каждый `setText` и каждую смену stylesheet — 14 КБ лога за несколько минут.
- Нет DPI-awareness: хардкод-пиксели разъезжаются на 125 % и 150 %.

## Визуальное направление

Выбран вариант **A2 «График-фон»** из трёх предложенных. Панель 280 × 280 логических пикселей:
ширина 280, высота складывается из отступов 13/12, шапки 23, четырёх строк по 52 и трёх
промежутков по 8.

Макеты в браузере — иллюстрация композиции, а не источник чисел. В макете подпись «280 × 200»
и значения в «горячем» состоянии (78 %, 61 %, 58 °C) не согласованы с порогами ниже; при
расхождении побеждают числа и пороги из этого документа.

Структура:

```
┌────────────────────────────────┐
│ ● SYSTEM              2s ago   │  шапка: точка = худшее состояние
│ ┌────────────────────────────┐ │
│ │ CPU              34% 4.5GHz│ │  подпись слева, значение и
│ │ ╭──────────────────────╮   │ │  вспомогательное справа
│ │ │╲__╱╲__╱╲___╱╲__╱╲___│   │ │  график = фон самой строки
│ │ ╰──────────────────────╯   │ │
│ ├────────────────────────────┤ │
│ │ RAM              11.4/32.0 │ │
│ │ ...                          │ │
│ ├────────────────────────────┤ │
│ │ GPU               61%  58°C│ │
│ │ ...                          │ │
│ ├────────────────────────────┤ │
│ │ VRAM             6.2/20.0GB│ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

Ключевые решения по визуалу:

- **История становится фоном строки, а не отдельным элементом.** Заливка площади до уровня
  нагрузки, высота 26 px в нижней части строки высотой 52 px, текст — над ней. Вариант A1
  (бар + отдельный спарклайн) отклонён: бар и линия дублируют друг друга и дают больше
  визуального шума при том же количестве данных.
- **Цвет приходит только с нагрузкой.** Спокойное состояние — холодный голубой
  (`#5ac8fa`). Янтарный и красный появляются исключительно при переходе порогов, чтобы цвет
  всегда был событием, а не фоном.
- **Числа моноширинные по цифрам** (`font-variant-numeric: tabular-nums`), поэтому разрядность
  не сдвигает соседние столбцы.
- **Шрифт Segoe UI Variable Display**, подпись 9.5 px uppercase с разрядкой 0.1em — чтобы не
  спорить со значением.
- **Матирование** — `rgba(16,18,24,.80)`, волосяная рамка `rgba(255,255,255,.10)`, тень
  `0 18px 44px -14px rgba(0,0,0,.75)`.

### Почему не настоящее размытие фона

PyQt6 не поддерживает `backdrop-filter`. `QGraphicsBlurEffect` размывает собственное содержимое
окна, а не то, что под ним. Настоящее размытие требует вызова DWM через `ctypes`:
`DWMWA_SYSTEMBACKDROP_TYPE` на Windows 11 (документированное API) либо
`SetWindowCompositionAttribute` с `ACCENT_ENABLE_ACRYLIC_BLURBEHIND` на Windows 10 20H1+
(недокументированное, но широко используемое).

**Решение: полупрозрачная заливка по умолчанию, настоящее матирование — опциональная галочка
в контекстном меню.** Разница видна только на пёстром фоне, а цена — нестабильный `ctypes`
внутри сборки PyInstaller. Галочка включается только явно и при отказе DWM молча возвращает
вид к режиму по умолчанию.

### Состав метрик

| Строка | Основное значение | Вспомогательное | Источник |
|---|---|---|---|
| CPU | нагрузка, % | `тек. / макс. GHz` | `psutil.cpu_percent`, `psutil.cpu_freq` |
| RAM | занято, GB | `/ всего GB` | `psutil.virtual_memory` |
| GPU | нагрузка, % | температура, °C | NVML |
| VRAM | занято, GB | `/ всего GB` | NVML |

Температура CPU сознательно **не** включена: `psutil` на Windows её не отдаёт, а доступные
источники либо требуют .NET-рантайм и прав администратора (LibreHardwareMonitorLib), либо
измеряют температуру зоны материнки, а не кристалла (WMI `MSAcpi_ThermalZoneTemperature`).
Вместо этого показывается частота — `psutil.cpu_freq()` работает на Windows штатно и проверен
на целевой машине (4501 МГц). Температура GPU остаётся: она приходит из NVML бесплатно и точна.

## Архитектура

Было три файла, где `overlay.py` отвечает и за окно, и за ввод мыши, и за отрисовку, а `main.py` —
и за lifecycle, и за сборку HTML-строки. Разделяем на модули с односторонними зависимостями.
Все модули лежат в корне репозитория, как и текущие — `AGENTS.md` требует именно этого.

| Модуль | Ответственность | Зависит от |
|---|---|---|
| `metrics.py` | Чтение железа. `Snapshot`, `SystemProbe`, `GpuProbe` | psutil, pynvml, wmi |
| `theme.py` | Палитра, пороги, размеры, типографика | ничего |
| `history.py` | Кольцевой буфер и прореживание до пиксельной ширины | ничего |
| `painter.py` | Отрисовка панели. Чистая функция: состояние → команды `QPainter` | QtGui, `theme`, `history` |
| `overlay.py` | Окно, позиционирование, ввод мыши | `painter`, `theme`, `settings` |
| `settings.py` | Сохранение позиции, прозрачности и опций | ничего |
| `main.py` | DPI, `QApplication`, поток сбора, таймер, трей-иконка | всё перечисленное |

`theme` и `history` не импортируют ничего из проекта. `painter` не знает про окно — получает
`snapshot`, `histories`, `rect` и рисует. Благодаря этому `painter` и `history` тестируются
headless в `QImage`, без запуска GUI.

### Модель данных

```python
@dataclass(frozen=True, slots=True)
class Snapshot:
    cpu_pct:  float | None
    cpu_mhz:  float | None
    cpu_max_mhz: float | None
    ram_used_gb: float | None
    ram_total_gb: float | None
    gpu_pct: float | None
    gpu_temp_c: float | None
    vram_used_gb: float | None
    vram_total_gb: float | None
    ts: float
```

`None` означает «не измерено» и рисуется как `--`. Отдельное поле `ts` нужно, чтобы счётчик
тиков не совпадал с реальным временем и история не заполнялась дублями при пропуске выборок.

### Сбор метрик

`GpuProbe` инициализирует NVML один раз за время жизни процесса и держит handle. `sample()`
забирает утилизацию, температуру и обе величины VRAM одним проходом. Наличие NVIDIA
определяется один раз при старте, а не через исключение на каждом тике.

WMI-фолбэк сохраняется для машин без NVIDIA, но перестаёт выдумывать значения: если частоту
свободного запуска получить нельзя, `gpu_pct` равен `None`, а не оценке `ratio * 30`.

`psutil.cpu_percent(interval=0.1)` — единственный блокирующий вызов, он остаётся, потому что
даёт настоящее среднее за интервал. `interval=None` даст мгновенное значение, которое для CPU
бесполезно: без интервала psutil сравнивает счётчики с предыдущим вызовом самого себя.

### Потоки

Сбор выносится в `QThread`-воркер, результат приходит сигналом `sampled(Snapshot)` в UI-поток.
UI-поток только рисует. Это убирает подёргивание окна на 100 мс каждые две секунды.

Опрос остаётся на `QTimer` в UI-потоке, но вместо выборки он только будит воркер. Пока воркер
занят, следующий тик пропускается — очередь выборок не копится.

### История

`deque(maxlen=60)` на каждую из четырёх метрик при тике 2 с — две минуты. При отрисовке
буфер прореживается до ширины области рисования: если точек больше, чем пикселей, берётся
экстремум на каждый пиксель, а не равномерная выборка, иначе всплески исчезают. При
`len < 2` рисуется плоская базовая линия, чтобы график не прыгал от нуля на первой выборке.

### Пороги

Все значения — в `theme.py`, не в коде отрисовки.

| Метрика | норма | внимание | критично |
|---|---|---|---|
| CPU, RAM, GPU, VRAM по процентам | < 80 | 80–95 | ≥ 95 |
| Температура GPU | < 70 °C | 70–80 °C | ≥ 80 °C |
| Частота CPU | состояния нет | — | — |

Частота показывается как `4.2 / 4.5 GHz` и не красится: она и так растёт при нагрузке, второе
кодирование того же сигнала только шумит. Если `cpu_freq().max` равен нулю (на части машин
Windows отдаёт `min = max = 0`), показывается только текущая частота — `4.5 GHz`, без дроби.
Точка в шапке отражает худшее состояние из всех метрик.

### Размеры строк

Строка — 52 px: 6 px верхний отступ, 18–20 px текст, 26 px область графика. Текст и график не
перекрываются. Радиус скругления строки 7 px, панели 14 px. Все размеры логические и умножаются
на масштаб из `screen().logicalDotsPerInch()`, а не задаются в физических пикселях.

### Ошибки

Правило: **не показываем число, которое не измерили.**

| Ситуация | Поведение |
|---|---|
| psutil упал | все строки `--`, точка в шапке серая, одна запись в лог |
| Нет NVIDIA | определяется при старте; WMI-фолбэк, недоступное остаётся `None` |
| Частичный сбой | RAM живой, GPU-строки `--` |
| Первая выборка | всё `--`, графики плоские |
| Ошибка записи лога истории | одна запись в лог, галочка снимается, виджет работает |
| Позиция уехала с отключённого монитора | прижать к геометрии основного экрана |
| Изменилась рабочая область (панель задач) | прижать к новой геометрии |

Логирование ограничено по частоте: не чаще одной записи на источник в минуту. Уровень — INFO
только на жизненном цикле (старт, смена настроек, ошибки источников), отладка отрисовки
выключена. Ротируемый файл.

## Взаимодействие

- **Перетаскивание — сразу**, без «режима перетаскивания» по двойному клику. Именно этот
  режим породил 13 коммитов с отладкой мыши и требует двух действий там, где хватает одного.
- **Правый клик — контекстное меню:** выход, вернуть в правый верхний угол, прозрачность,
  поверх всех окон, настоящее матирование, писать историю в файл.
- **Колесо мыши** — прозрачность, как сейчас.
- **Средняя кнопка** — выход, сохранён как алиас.
- **Режим случайного цвета удаляется.** Он не даёт ничего, кроме «поделкового» вида.
- **Трей-иконка** — минимальная: двойной клик возвращает панель в правый верхний угол (страховка,
  если виджет утащили за пределы экрана), правый клик открывает то же контекстное меню. Иконка
  генерируется в коде `QPainter`-ом, файла-ресурса в сборке не появляется.

Позиция, прозрачность и опции сохраняются в JSON рядом с исполняемым файлом, с учётом
PyInstaller: путь берётся из `sys.executable`, если приложение собрано, иначе от `__file__`.
При повреждённом или отсутствующем файле используются значения по умолчанию, загрузка не
падает.

## Тестирование

Ставится `pytest`. GUI не требуется.

| Модуль | Что проверяем |
|---|---|
| `theme` | Каждое значение попадает ровно в одно состояние; границы порогов включаются в «критично» |
| `history` | `maxlen` соблюдается; прореживание до 1 px не теряет максимум; 0 и 1 точка не ломают геометрию |
| `metrics` | `Snapshot` собирается при подставленных заглушках; NVML-проба один раз определяет отсутствие GPU и не вызывает `nvmlInit` повторно; недоступное значение даёт `None`, а не `0.0` |
| `painter` | Отрисовка в `QImage` не даёт пустой результат; для каждого из трёх состояний есть эталон; отсутствие данных не ломает геометрию |

Эталонные снимки `painter` хранятся в `tests/golden/`.

## Приёмка

1. Панель совпадает с макетом при 100 % и 150 % DPI, ничего не обрезано.
2. Окно не дёргается: процесс не больше 3 % CPU; `psutil.cpu_percent(interval=...)` не
   вызывается из UI-потока.
3. `app_debug.log` меньше 5 КБ после 10 минут работы.
4. `pytest` зелёный, включая эталоны отрисовки.
5. Без NVIDIA виджет работает, GPU-строки `--`, в логе нет спама исключений.
6. `build_exe.bat` → `dist\Monitor.exe` стартует с чистым PATH.
7. Позиция и прозрачность переживают перезапуск.

## Что удаляется

| Объект | Причина |
|---|---|
| `run_widget.py` | Не работает: импортирует несуществующий пакет, создаёт второй `QApplication` |
| `DraggableLabel.setText` / `setFont` | API `QLabel` внутри виджета, который больше не `QLabel` |
| Ручной детект двойного клика | Заменён на `mouseDoubleClickEvent` |
| Режим случайного цвета | Нефункционален как фича, вредит виду |
| Синтез GPU-нагрузки в WMI-фолбэке | Выдуманное значение вместо измеренного |
| `_bg_alpha_percent` / `bg_alpha` | Два источника правды; остаётся одно поле |
| Упоминание `metrics_history.log` в документации без реализации | Либо реализация opt-in, либо документ приводится в соответствие |

## Смежные правки вне основной работы

- `.gitignore`: убрать `*.spec` или добавить исключение `!Monitor.spec`, иначе спека сборки не
  версионируется и сборка невоспроизводима.
- `README.md` и `AGENTS.md`: привести таблицу управления, список файлов и упоминание лога истории
  в соответствие с новым поведением.
- `requirements.txt`: добавить `pytest` в dev-зависимость.

## Отклонённые альтернативы

| Вариант | Почему отклонён |
|---|---|
| Оставить `QLabel` с HTML, поменять стили | Не даёт скруглений с антиалиасингом, тени, графиков и выравнивания цифр — то есть ровно того, ради чего затевалась переработка |
| Переход на PySide6 или QML | QML тянет QtQuick целиком ради десяти элементов; выигрыш в вёрстке несопоставим с добавлением рантайма в сборку |
| Web-оверлей на прозрачном окне | Появляется второй рантайм в процессе, теряется нативный трей и `psutil`-семантика |
| Сохранить режим случайного цвета | Это и есть ощущение поделки; в требованиях его нет |
